Porchlight: three directions

Same tokens, same rule (amber = captured and sourced, unlit = gap, red = error only). The directions differ in how the light shows. Try hover, Tab for focus, and "Light it" on each gap card.

C+A · Lit window (your pick)

C's warm, filled window with A's soft glow around it. A gap stays a dark window. Calm at rest, alive when knowledge lights up.

A · Lamplight

Lit things glow softly, like a lamp in a window at night. The warmest, most "alive". Risk: glow can feel decorative if overused.

B · Filament

Light is a thin, exact amber line. The most precise and Linear-like. Risk: may read too cool for "warm".

C · Window

A lit card is a warm, filled window; a gap is a dark one. Calm, Things-like. Risk: tinted fills can look like status colours.
